# Product Overview

**rig-postgres** is a PostgreSQL-based vector store implementation for the rig framework. This library provides vector database capabilities using PostgreSQL with the pgvector extension, enabling efficient storage and retrieval of high-dimensional vectors for AI/ML applications.

## Key Features
- PostgreSQL integration with pgvector extension
- Vector similarity search capabilities
- Part of the larger rig framework ecosystem
- Async/await support with Tokio runtime

## Target Use Cases
- AI applications requiring vector storage and retrieval
- Semantic search implementations
- Machine learning model embeddings storage
- RAG (Retrieval-Augmented Generation) systems
